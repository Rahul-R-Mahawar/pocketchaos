04 · System architecture & technical trade-offs

A monorepo of three apps around one contract.

Zod validates the environment at startup fail fast

JWT_SECRET (≥ 32 chars), MONGODB_URI and CORS_ORIGINS have no defaults. A bad config stops the boot and names the key, never its value.

Short-polling instead of WebSockets simplicity

2 s polls, paused in hidden tabs, back off on 429. Stateless, works behind any host or proxy; the cost is up to 2 s of staleness.

Deterministic AsyncStorage queue correctness

One serialized writer, persisted sequence numbers, single-flight sync, at-least-once replay with one Idempotency-Key per request.

Key-only pairing least privilege

The phone never holds a JWT. The pairing view hides upstream URLs and mock bodies; 32⁶ keys plus a 120/min rate limit.

05 · Security & guardrails Engineering & Code Quality · 30%

Secure by contract, proven by negative tests.

01Zero hardcoded secrets

Secrets and URLs live only in the environment. env.ts validates them with Zod at startup; only .env.example files are committed.

Canary builds of web + mobile bundles leaked 0 secrets · 11 env-validation tests

02JWT ownership isolation

Every /api/endpoints route needs a Bearer JWT pinned to HS256; every query is scoped to req.user.id.

alg=none · HS512 · expired · wrong-secret → 401 · user B cannot read or toggle user A's endpoints

03Bounded timers & rate limits

delayMs is validated to 0–10,000 ms and clamped again at runtime, so even a tampered database row cannot hold a request longer.

delayMs 10000 accepted · 10001 rejected · stored 999999 → sleeps 10000 · proxy 600/min · auth 30/15 min

04SSRF protection

isSafeExternalUrl: http(s) only; blocks loopback, RFC 1918, link-local 169.254.169.254, private IPv6. DNS is pinned at connect time.

65 SSRF unit tests · DNS rebinding → 403 · redirects to metadata never followed · VettedUrl type

08 · Human validation & learning from AI failures

Where AI was wrong, and what we changed because of it.

The SSRF guard blocked the whole internet log 1.1

AI wroteOne net.BlockList for IPv4 + IPv6; the ::ffff:0:0/96 rule matched every IPv4 address.
HumanTested the allow-list as hard as the block-list: 8.8.8.8 must pass. Split per address family.

Built against an empty contract log #3

AI wroteCONTEXT.md was 0 bytes on disk; the model filled the gap with its own defaults → 5 contract divergences.
HumanRealigned envelope, validation, fault semantics. New rule: wc -c .ai/*.md pre-flight; empty context = blocker.

The offline queue could erase itself log 5.6

AI wroteAfter a failed storage read, the next enqueue built on an empty state and overwrote every saved request.
HumanFailing test first; now nothing is written until a read succeeds. Same bug class found in settings (5.11).

"INTACT" for corrupted payloads log 5.13

AI wroteMajority-vote schema detector; at 100% corruption it called 16.8% of corrupted 4-field bodies INTACT.
HumanMeasured against the backend's real corruptor over 1,000 batches; undecided fields → UNVERIFIED: 1.5%.
How context evolved

CONTEXT.md went from 0 bytes to the engineering contract (commit 1aa272e) and the code was realigned to it. The workflow gained failing test first and an empty-file pre-flight; the log gained observed vs. review labels and one rule: a green run counts only if the test count is right (Jest once passed with 0 tests).
